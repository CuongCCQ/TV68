# TV68 — Launcher Android TV cho gia đình

Dựa trên launcher của [CleanYourTV](https://github.com/Gathin23/cleanyourtv) (MIT, xem `LICENSE-cleanyourtv`), thêm:
- Ảnh gia đình làm nền (thư mục `TVHome` trên USB hoặc `Pictures/TVHome`)
- Thời tiết
- Chế độ trẻ em khoá bằng PIN

## Cài
Trên TV mở app **Downloader**, nhập mã **9453086** → Install → bấm Home → chọn TV68 → Luôn luôn.

APK luôn mới nhất: `release/TVHome.apk` (tự build bởi GitHub Actions mỗi lần push).
